# Project Learning Log

Concise chronological record of verified data findings, modelling experiments, and safeguards.

## 1. Data & Integrity Audit
- **South African archive:** 1,715,779 1-minute rows across 10 sites (`stations.csv` lists working coordinate candidates; site 13 Saldanha Bay has two unresolved alternatives). 62 `TOL_*` columns include all 25 competition bands (31.6–7943.3 Hz). Nominal `12000` Hz recorder rows contain finite 6.3/7.9 kHz values (export convention unverified).
- **15-min background index (`reports/eda/background_window_index.csv`):** 88,143 non-overlapping complete windows across 8 stations (Cape Recife max run = 13, Riy Banks max run = 13 -> excluded).
- **Chronological split v2 (`reports/eda/background_split_manifest_v2.csv`):** 67,463 train / 16,946 validation / 3,193 gap-excluded / 541 station holdout (Fish Hoek 297, Sea Point 244). Zero run overlap; 9–49 day train/val gaps.
- **`Test.csv` (inference-only):** 1,500 × 375 features; 18,350 missing cells across 725 rows, all occurring as whole 25-band minute omissions (624 missing `m01`, 100 missing `m15`). Never used for fitting or calibration.
- **VTUAD (`v1.3.0`, Concept DOI `10.5281/zenodo.22274549`):** 525 mono 32 kHz PCM_16 WAVs passed SHA-256 verification. Key pitfalls found:
  1. 22 files in `vessel/` have `label == 'background'` (`class_code == 0.0`) -> isolated with the 16 `background/` files (38 total).
  2. Strict-interval WAV durations match `span_sec`, whereas 168 differ from `metadata.csv`'s `duration_sec` by up to 300 s -> always read actual WAV frames.
  3. Publisher split leaks 57/178 hulls across splits -> rebuilt hull-disjoint split v2 (`410` train / `77` val clips, 0 shared hulls; `dredger` & `pilotvessel` have 1 hull each -> train-only).

## 2. Synthetic & Leaderboard Progression
- **Exp 001 (200 train / 80 val, discrete shares):** 375-feature RF RMSE `0.197845` vs constant `0.249648`. Feature-family ablation showed 96 combined global/spectral/temporal summaries dropped exploratory RMSE to `0.119687`.
- **Exp 002 (1,200 train / 300 val, station-balanced, continuous shares):** Preselected 96-feature RF reached RMSE `0.112061`, MAE `0.073236` (constant `0.250364`, raw 375 `0.144499`, 50 spectral `0.147717`). Errors concentrated on 1–2 min weak additions (22/30 worst errors).
- **Submission 001 (`pBUapzRu`, commit `aaf4748`):** Fixed per-window max-shift pipeline scored provisional public `1 - RMSE = 0.761536` (`share RMSE = 0.238464`), diagnostic `score_added_vessel` AUC `0.517533` (shared same output as `share_added_vessel`, no separate classifier). On synthetic Exp 002 val, that same pipeline gave RMSE `0.166477` and AUC `0.953386` — confirming severe synthetic-to-public domain shift.
- **Exp 003 (48 matched pairs × 6 masks):** Original representation beat `submitted_max_shift` on 4/6 masks (complete RMSE `0.127155` vs `0.178687`), while first-minute and both-edge masks were sensitive to single-source deletions.
- **Exp 004 (frozen source pools, `exp004_eval` n=300):** Original RF RMSE `0.114430` (AUC `0.981296`) vs max-shift RF `0.150893` (AUC `0.978653`).

## 3. Spectral Contrast, Source-Disjoint Exp 007 & Descriptive Synthesis
- **Real-acoustic 6-station audit (`exp004_train`, 460 runs, cap 120/site):** Median run-window means span `61.520` (Saldanha Bay) to `90.604` (Bird Island) in source-export units; peak-normalized spectral-shape RMS distances vs VTUAD range from `7.477` (St Francis) to `26.202` (Durban, `n=1`).
- **Exp 005 (5,520 scenarios, 1,840 triplets):** Replacing VTUAD spectra with background-matched controls significantly reduced within-window temporal spectral excursion (median `+3.50` to `+6.57` dB on 1-min events), showing models could exploit unnatural source–background spectral contrast.
- **Exp 006 / 006B (120 internal dev pairs):** Contrast-varied training reduced RMSE (`0.133224 -> 0.114353`) and lifted AUC (`0.847977 -> 0.877137`), but raised non-injected-control FPR at 0.50 (`0.233333 -> 0.375000`). Exp 006C found 112/120 pairs in one connected source component, prompting a clean pre-pairing split in Exp 007.
- **Exp 007 (source-disjoint train/calibration/assessment, 120 assessment pairs):**
  - Contrast-varied RF reduced assessment RMSE `0.114236 -> 0.094566` (`-0.019670`, ~17.2%; run-bootstrap 95% CI `[-0.00041, 0.04230]`) and raised AUC `0.848328 -> 0.886421`.
  - Fixed-0.50 non-injected FPR increased `0.16667 -> 0.30000`; calibration-selected threshold (`0.55`, targeting FPR ≤ 0.25 on calibration) yielded assessment FPR `0.23333` and TPR `0.85294`.
  - **Hybrid policy** (contrast-varied regressor + original 0.50 detector) pairs `0.094566` RMSE with `0.16667` FPR, capturing the accuracy/specificity trade-off.

## 4. Modeling v2 Benchmark & Submission #2 Live Leaderboard Diagnosis
- **Modeling v2 (`scripts/modeling_v2_*.py`):** Aligned all VTUAD (`525`) and HearMyShip (`96`) clips to exact 2s Hann base-10 deci-decades (`EXACT_CENTRES`), removed max-shifting via constant `R_0=100 dB` linear superposition, masked missing `Test.csv` minutes cleanly, and benchmarked 11 deterministic models (`Constant_Mean`, `Physics_q15`, `V1_RF_MaxShift`, `Linear`, `RF_v2`, `HistGBM`, `LightGBM`, `XGBoost`, `CatBoost`, `CNN2D`, `Ensemble_v2`).
- **Offline vs. Public Divergence:** `Ensemble_v2` reached `0.8747` validation (`AUC 0.9725`) and `0.8833` unseen Fish Hoek + Sea Point holdout (`AUC 0.9365`; cutting RMSE by 27.5% vs `V1_RF_MaxShift`). However, Submission #2 (`submissions/candidate_v2_ensemble.csv`) scored public LB `1 - RMSE = 0.77501743` (`RMSE = 0.224982569`) with diagnostic `ROC AUC = 0.548377777` (Rank `508`, vs Submission #1 `0.761536` / `0.517533`).
- **Root-Cause Audit:** Global median subtraction removed broadband offset `C`, leaving frequency-dependent hydrophone transfer curves $h(f)$ (spectral tilt and modal ripple) unmodeled alongside sharp South African coastal non-vessel transients (VLF swell, 63–125 Hz reef bursts, telemetry glitches).

## 5. Modeling v3 Hard-Negative Architecture & Tilt-Shortcut Discovery
- **Simulator & Architecture (`scripts/modeling_v3_*.py`):** Scaled datasets to `10,000` train / `2,000` `val_standard` / `1,500` `val_hard_event` / `541` `holdout` (`0` cross-fold/cross-split `bg_run_id` or `hull_id` overlap), raised zero fraction to `41.6%`, added four stratified event pools (`ambient_normal`, `hard_event`, `reef_active`, `glitch_drop`), removed `mask_m01_missing` shortcuts, added `180` linear-excess features, and introduced 7-channel SE-ResNet `CNN2D_v3` plus Hurdle GBDT regressors (`P(vessel) * E[share | pos]`).
- **Results & Pitfall Caught:** `Ensemble_v3` lifted `val_cal_hard` `1-RMSE` to `0.8788` (`AUC 0.9634`), `val_standard` to `0.9007` (`AUC 0.9743`), and unseen `holdout` to `0.8971` (`AUC 0.9686`). Yet gain inspection found `proto_spec_logit` taking `47.0%` of LightGBM split gain (`25.8%` mean norm) by memorizing ONC-vs.-SA spectral tilt, and `bundle_v3.joblib` pickled a `__main__` transformer class.

## 6. Modeling v4 Exact h(f) Calibration Invariance
- **Algebraic Cancellation (`scripts/modeling_v4_features.py`):** Eliminated `proto_spec_logit` and raw-spectrum `ex_tot_db_*` predictors in favor of `205` features anchored by `71` exact frequency-response-invariant temporal excess residuals $R(t,f) = X(t,f) - Q_{0.20, t' \in \Omega(f)}(X(t',f))$, proving `<= 1.60e-14` difference under `+6 dB/dec + 2.5 dB cosine ripple` calibration curves $h(f)$ and `0.0` difference across invariant CNN channels `[0,1,2,3,5,6]`.
- **Strict SA Simulator & Clean Bundle (`scripts/modeling_v4_simulator.py`, `scripts/modeling_v4_train.py`):** Separated backgrounds into 5 strict physical strata (`strict_hf_ship`, `vlf_surf`, `reef_active`, `glitch_drop`, `ambient_normal`), simulated sharp `2–5 min` VTUAD blocks, injected `65.3%` calibration warping in `train` (`100%` in `val_cal_hard`), removed all custom `__main__` classes from `models/v4/bundle_v4.joblib`, and fitted temperature-calibrated OOF blends (`T = 0.9296`).
- **Verified Gains (`submissions/candidate_v4_ensemble.csv`):** `val_cal_hard` `0.8933` (`AUC 0.9800`, `zero_rmse 0.0664`), `val_standard` `0.9137` (`AUC 0.9837`), and unseen `holdout` **`0.9219`** (`RMSE 0.0781`, `AUC 0.9737`, `zero_rmse 0.0329`, `-30.0%` RMSE vs `Ensemble_v2`). Top tree splits shifted to physical acoustics (`ex_frac_hf`, `hf_contrib_q20`, `R_max_b24`, `m_hf_lag1`, `ex_curv_mid_vs_ends`). Continuous `holdout +37.5 dB` reload diff = `0.0`; `Test.csv` `p95_diff = 0.0` (`max_diff = 2.32e-3` from 1-ULP IEEE-754 rounding at exact `8.0 dB` jump in row 27, noting smooth sigmoid counts as a v5 refinement).

## 7. International Acoustic Standards Benchmark & Boundary Research
- **Suite (`scripts/standardized_evaluation_suite.py`, `docs/LITERATURE_STANDARDS_AND_BOUNDARIES.md`):** Evaluated `Constant_Mean`, `Physics_Robust_q20`, unsupervised `RPCA_Unsupervised`, `Ensemble_v2`, `Ensemble_v3`, and `Ensemble_v4` across ISO `18405:2017`, IEC `61260-1`, NPL GPG `133`, ADEON, JOMOPANS $L_{\text{excess}}$ MAE, Lin's CCC, NSE, regime-wise RMSE, Brier decomposition, `ECE_10`, PCEN, and `-6` to `+10 dB/dec` tilt sweeps.
- **Key Standard Findings:** Unsupervised `Physics_Robust_q20` (`val_cal_hard 0.3630`, `NSE -4.028`) and `RPCA_Unsupervised` (`0.5413`, `AUC 0.500`) fail in dynamic coastal telemetry, while `Ensemble_v4` reaches `Lin CCC 0.920` (`0.924` holdout), `JOMOPANS L_ex MAE 0.547 dB` (`0.308 dB` holdout), `ECE_10 0.0273`, and sustains `0.9561` ROC AUC (`0.0929` `zero_rmse`) at extreme `+8 dB/dec` tilt.
